# Sitemap & Link Inventory — MediaOne

> Stock of every article/story page on the site, plus the link audit behind the
> guarantee that **no internal click 404s**. Generated 2026-08-12 against the
> static build (292 pages).

## How this was produced

1. **Stock** — every story page is generated from `src/lib/sections.ts`
   (`/story/<slug>`), plus the article-type pages under `/magazine`,
   `/shelf`, `/videos/watch`, `/programs`, `/travel`, `/features` and the
   section desks (`/kerala`, `/india`, …) generated by `src/pages/[section].astro`.
2. **Audit** — built the site (`npm run build`), walked every emitted HTML page,
   collected every internal `href`, and flagged targets with no page. 90 broken
   targets were found; the five `/_astro/*.css` entries were hashed-asset false
   positives.
3. **Fix** — remapped every broken link to the closest live page (a matching
   story where one exists, otherwise the section desk), and added the missing
   `/fact-check` desk so the nav link resolves.

Re-run the audit:

```bash
npm run build
# then walk dist/ for hrefs whose target has no dist/<path>/index.html
```

## Link audit — what was broken and what happened

90 targets were linked but had no page (5 were hashed CSS assets — false
positives). Root causes and fixes:

### 1. Live-site article URLs (45) — remapped to closest local page

`src/lib/home4-data.ts` (homepage + every desk page) carried URLs captured
from the live mediaoneonline.com site (`/kerala/…-332230` etc.). No local page
matches them, so each was remapped to the closest local story or the section
desk. Where the local fixtures already had a topical match, the story page was
used instead of the desk:

| Original (live path) | Now points to |
|---|---|
| `/kerala/rain-warning-…-332230` | `/story/rain-alert` (local rain story) |
| `/kerala/lorry-driver-…-332255` | `/story/ernakulam-accident` (local lorry story) |
| `/mediaone-shelf/analysis/ayodhya-…-329589` | `/magazine/ayodhya-ram-mandir-donation-scam-329589` (same article, local page) |
| `/mediaone-shelf/analysis/voters-list-…-328638` | `/magazine/voters-list-and-passport-328638` (same article) |
| `/mediaone-shelf/analysis/mediascan-latest-issue-328205` | `/magazine/mediascan-latest-issue-328205` (same article) |
| `/mediaone-shelf/analysis/buddha-purnima-analysis-322500` | `/magazine/buddha-purnima-analysis-322500` (same article) |
| every `/kerala/<slug>` (rest) | `/kerala` desk |
| every `/india/<slug>` | `/india` desk |
| every `/world/<slug>`, `/america/<slug>` | `/world` desk |
| every `/entertainment/<slug>` | `/entertainment` desk |
| every `/sports/<slug>` | `/sports` desk |
| every `/gulf/<country>/<slug>` | `/gulf/<country>` desk |
| `/lifestyle/<slug>` | `/lifestyle` desk |
| `/videos/how-metas-…-332262` | `/videos` |
| every `/mediaone-shelf/…` (shelf band, rest) | `/shelf` |

### 2. Prefix mismatch — `mediaone-shelf` vs `shelf` (24 links)

`src/lib/shelf-data.json`, `src/lib/magazine.ts` and the old-home data used
the live site's `/mediaone-shelf/…` paths; the local site serves shelf under
`/shelf`. Fixed in:

- `shelf-data.json` — all 8 nav links + 29 article hrefs → `/shelf/<slug>`
  (the article pages exist; the nav pointed at the wrong prefix)
- `magazine.ts` — 4 article hrefs → `/magazine/<slug>` (their own pages)
- `home-data.ts` — 3 shelf links → `/shelf/<slug>` / `/shelf/analysis`

### 3. Nav links with no page (3 targets)

- `/fact-check` (345 links) — the mega-nav promised a desk the routing never
  generated. **Added a `fact-check` section** to `src/lib/sections.ts` (3
  fixture stories) → `/fact-check` now builds as a real desk.
- `/national` (15) — stale band href in `home4-data.ts` and `home-data.ts`
  → `/india`.
- `/shelf/rack` (33) — shelf nav entry with no rack page → `/shelf`.

### 4. Stories referenced but never generated (14)

`home-data.ts` (old-home/breaking/lab pages), `gold-prices.ts` and demo
pages referenced `/story/<slug>` values that `sections.ts` doesn't contain
(`joseph-vazhackan-kpcc`, `kanthapuram-liquor-tax`, `gold-2020`,
`aiyf-march`, …). Remapped to the section desk or to the real gold story
(`/story/gold-price-record`).

### 5. Stale entry in `sitemap.xml.ts`

`/design/index` → `/design` (no such page). `/sitemap` added to the static list.

## Result

After the fixes the full crawl finds **zero** unresolved internal page links
(only the hashed `/_astro/*.css` asset refs, which exist). The audit script
lives in this repo's build pipeline notes; re-run after any data change that
touches `href`.
